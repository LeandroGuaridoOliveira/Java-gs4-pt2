Rotas Públicas & Privadas
Arquitetura de Rotas e Permissões
Rotas Públicas (Acesso Livre)
  • / : Página Inicial institucional.
  • /produtos : Catálogo de produtos (somente leitura).
  • /produtos/detalhes/{id} : Ficha técnica do produto.
  • /login : Tela de autenticação do operador/admin.
Rotas Privadas (Exigem Autenticação)
  • /produtos/novo : Cadastro de novos itens (USER / ADMIN).
  • /produtos/editar/{id} : Edição de produtos (USER / ADMIN).
  • /produtos/excluir/{id} : Exclusão do banco de dados (Apenas ADMIN).
